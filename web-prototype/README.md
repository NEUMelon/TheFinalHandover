# 《最后一次交班》UI Prototype v0.1（谜题二垂直切片）

可运行、可点击、可截图的高保真界面原型。覆盖 10 类界面，并能从打卡一路点到衡等级提升，走完谜题二“咔哒在左”的完整交互。

依据：`00_主项目文档` v1.1、`01_圣经/03_UI设计系统_v0.1`（下称 UI-DS）、`02_母项目VS/01_四谜题事实链_v0.1`、`01_圣经/02_美术圣经_v0.1`、`01_圣经/05_展板设计系统_v0.1`。设计 Token 与 UI-DS 同名同值（`css/tokens.css`）。

> **重要**：本原型的代码、矢量图形、纹理和截图都由 AI 辅助工具编写生成。按主项目文档 §8.4，“代码辅助”允许，但**任何最终视觉资产不得由 AI 生成**。所以 `screenshots/` 里的图只用于内部评审和交互说明，不能直接放进展板。正式交付前要按第 7 节的清单由团队人工重做视觉资产，并在 `80_合规/AI使用日志` 记一笔。

## 1. 打开方式

1. 双击 `index.html`。推荐最新版 Chrome 或 Edge，不需要联网，不需要本地服务器。
2. 舞台固定 1920×1080，按窗口等比缩放；按 F11 全屏观感最好。
3. 声音在第一次点击后才会响（浏览器的自动播放限制）。占位音频是程序实时合成的，见第 6 节。
4. 进度存在浏览器本地（localStorage）；主菜单的“继续”卡在有存档时可用。暂停菜单里可以清除存档。
5. **单文件版**：`dist/最后一次交班_UI原型.html` 把字体、样式、脚本全部内联成一个约 2MB 的文件，可以单独发给别人双击打开。改了源文件后用 `python3 tools/build_single.py` 重新生成。
6. **手机 / 平板**：建议横屏。触屏上右上角有“目录”按钮代替 Esc；时频图框选和接班人签名都可以用手指拖。

## 2. 完整流程怎么点

| 步骤 | 操作 | 你会看到 |
|---|---|---|
| 1 打卡 | 在右侧卡架点“开始”考勤卡（或 ↑↓ 选卡、Enter） | 卡片飞进打卡钟插槽，“咔—哒”，钟跳到 16:00，告示“接班人”栏写上“林小满” |

| 3 1983 贴页 | 点右下折角或按 D 翻页；点左页“设备记录” | 老周 1983 年手写“咔哒在左，是轴承；在右，是齿轮。”，取得**贴页 3**（飞入交班本） |
| 4 去 LT01 | 按 A 翻回，点红字“→ 去 LT01 听” | 车床主轴箱 + 林小满的衡调试平板 |
| 5 取听针 | 按 T 打开工具箱，点“听针”（或直接按 1） | 鼠标变成听针；卡尺、螺丝刀标“此处用不上” |
| 6 L1 / R1 | 点 L1 或 R1 的铜牌 / 测点 | 听针贴上测点，平板出现时频图，播放头走动，每声“咔哒”对应一条竖向条纹闪亮 |

| 10 选错一次（可选） | 例如经验判断选“在右，是齿轮”，按确认章 | 该格安全黄斜纹边 + “规则冲突”，衡日志反相闪一下，播放“换过齿轮咔哒还在”的仿真 |
| 11 选对 | “嗡”里夹着“咔哒” / 咔哒在左，是轴承 / L1 测点、本机 2–4kHz 共振带内的周期冲击 = 后轴承缺陷；齿轮看啮合边频，按确认章 | 三格盖“合格”章 → 规则卡生成：手写卡片点阵化飞向衡屏幕，Rule ID 逐字打出，PENDING 0.8 秒后 CONFIRMED，同一帧盖章、交接状态板第二盏灯熄灭（600ms 余辉） |
| 12 等级提升 | 自动弹出 | “技术等级考核合格通知”从下方滑入，盖“合格”章，衡：一级 → 二级。2.5 秒后点任意处收起，对讲机里周建国：“嗯。” |

结局签名不在谜题二流程里，从暂停菜单的演示目录进入（第 3 节）。

## 4. 截图导出

截图脚本用 Playwright + Chromium（`npm i playwright`，再 `npx playwright install chromium`；已装在全局的话用 `NODE_PATH` 指过去）。

```bash
# 13 张关键界面，1920×1080，输出到 screenshots/
node tools/screenshots.cjs

# 展板印刷用 2 倍图（3840×2160）
SCALE=2 node tools/screenshots.cjs screenshots/2x

# 只导出文件名含“三联板”的
node tools/screenshots.cjs screenshots 三联板

# 自动点一遍完整流程（19 项检查，含手机横屏触屏），每一步截图到 screenshots/flow/
node tools/flow_test.cjs

# 对单文件版跑同一套检查
node tools/flow_test.cjs screenshots/flow dist/最后一次交班_UI原型.html

# 任意页面单张截图
node tools/shot.cjs index.html?jump=mes out.png 1920 1080
```

手动截图：浏览器窗口调到 1920×1080（或 F11 全屏的 1080p 屏幕），用演示目录跳到界面后系统截图即可，1:1 不缩放。

当前 `screenshots/` 内容：`01`–`10` 为 13 张关键界面；`flow/` 为自动流程测试的 19 张逐步截图（最后 3 张是手机横屏触屏）；`00_资产自查_修正前.png` 是早期素材自查的存档。

## 6. 字体

全部为 SIL OFL 1.1 开源字体：思源宋体（Noto Serif SC）、思源黑体（Noto Sans SC）、JetBrains Mono，以及三款手写占位（志莽行书 = 老周体占位、龙藏体 = 建国体占位、霞鹜文楷 = 林小满笔迹占位）。来源、版本、用途、与 UI-DS 的差异和裁切方法见 [`fonts/FONTS.md`](fonts/FONTS.md)。改了界面文字要重跑 `tools/subset_fonts.py`。

## 7. 资产状态三份清单

### 7.1 已经达到高保真的

这些是版式、信息层级、文案和交互，已经接近展板可用的程度（但仍受第 7.3 节的 AI 条款约束，最终展板图需要团队按此重新制作）。

- **10 类界面的版式与信息层级**：1920×1080 基准，颜色、字号、间距、动效时长全部取自 UI-DS Token；旧系统（暖、纸、手写）与衡（冷白、细线、等宽）两套语言分开，没有霓虹、HUD、网页仪表盘的观感。
- **衡的全部界面**：MES 三栏（设备 / 日志 / 知识库 / 诊断 / 规则卡 / 交接 / 等级 / 点检）、调试平板 DIAG、规则卡屏幕侧、日志逐字打出（20ms / 字）、规则冲突反相 240ms、状态标签 DRAFT / PENDING / CONFIRMED / UNNAMED。全部由文字和细线构成，不拟人。
- **时频图与边频指示**：按事实链与听音原型的参数合成（冲击间隔约 0.29s、2–4kHz 本机共振带、GMF 620Hz、边频指标 0.18 / 阈值 0.35），播放头与咔哒同步、条纹闪亮（B-3），框选判定规则与听音原型 §4.1 一致。
- **交互逻辑与状态机**：谜题二完整闭环（取证 / 未取证、选错反馈与仿真、三级页边提示 90 / 180 / 300 秒、规则卡生成时间线、灯熄与升级同帧、存档继续），自动流程测试 15 项全部通过。
- **纸面表单的排版与文案**：交班本点检表、三联对应单、规则卡纸面（Rule ID / Source / Measurement Point / Feature / Binds / Status 完整 ZHOU_CLICK 示例）、技术等级考核合格通知、技术等级证、职工档案卡、结局交接页。
- **口径**：时间压缩、B-1 / B-2 / B-3、1983 只记位置与听感、“夹在工牌套中的工作照”、1965“第一次以师傅身份带徒”均已写进界面，见 `口径与待回写变更项.md`。

### 7.2 仍是 placeholder 的

- **全部声音**：L1 / R1 听针循环、咔哒、仿真对比音、打卡、翻页、盖章、继电器、抽屉，都是 WebAudio 实时合成。界面上标的 `L1_normal.wav` 等是预留文件名。正式版按声音圣经实录。
- **三款手写字库**（老周体、建国体、林小满笔迹）和衡界面的中文等宽字（应为 Sarasa Mono SC）。
- **手写显现动画**：现在是从左到右揭开，UI-DS 要求的是按笔顺的矢量笔画动画。
- **翻页**：平面 3D 翻转，没有纸张卷曲；时长放慢到 520ms 方便演示，UI-DS 规定 240ms（`--D-Flip`）。
- **规则卡点阵飞散**：通用粒子效果，没有按手写笔画拆点。
- **记忆层“版画颗粒”**：本切片没有记忆显影场景，只在照片上用了网点效果。
- **剧情时钟**：按游玩时间粗略推进（约 9 秒一分钟），没有接剧情节点。
- **范围外的谜题**：谜题一只作为已完成状态出现；谜题三、四只以规则名和状态出现，没有界面。

## 8. 已知问题

- 等宽日志里的中文用思源黑体顶替，中英混排的列宽和严格的 2:1 略有出入。
- 衡平板与交班桌小屏的日志按行截断，长句只显示开头。
- 演示目录直达的界面会自动补齐状态，所以直达截图里的时间（如 17:32）比实际游玩稍早。
- 浏览器禁止自动播放时，第一次点击前没有声音；无音频设备时播放头按页面时钟推进，交互不受影响。
- 手机竖屏时舞台会缩得很小，页面底部会提示横过来看。
- 结局给新规则命名要用键盘输入；手机上点输入框会弹出系统键盘，可能遮住半个画面。
