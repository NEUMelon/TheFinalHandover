# 交班桌 + 台灯 · 说明

由 AI 辅助工具编写（Stage 3 道具组 3D 资产，2026-10-15）。数据来源：WorkshopGraybox.cs、ContentDB.World.cs / Puzzles.cs、WorldPresenter.cs、02_车间白盒规格_v0.1.md、01_圣经/02_美术圣经_v0.1.md、01_世界观圣经_v0.1.md。

## 资产

- 资产：`LSB_ENV_PRP_ShiftDesk_v01`（Mid，预算 8–12k）。实测 **2,748 三角**（Desk 1,624 / DeskLamp 820 / Drawer 260 / GlassPlate 44），低于预算——中景下桌子是简单的四腿办公桌，多出的预算没有硬加。
- 摆放：局部原点 = 桌底面中心 → 世界 (26.5, 0, 13.0)，yaw 0；+X 东（坐人一侧，N1 看到的一面），+Y 北。尺寸按白盒规格 1.6 × 0.8 × 0.76（台面上沿 0.76）。
- 部件：Desk（桌体）、GlassPlate（玻璃板，0.7605–0.772）、Drawer（枢轴 = 灰盒 DrawerBox (26.55, 0.62, 13.55)，跟灰盒 rigid 平移 +0.3 m）、DeskLamp（台灯）。
- 年代 / 造型：1970 年代式样清漆实木办公桌（深栗色），四腿收分、牙板、脚踏横枨；东侧封边用“磨亮木”（手肘、交班本几十年磨出的包浆，美术圣经 §4“包浆：交班桌边”）；东南角封边两处烫痕贴花（美术圣经 §6“桌角烫痕（不画香烟）”）；铝拉手 + 锁眼。台灯：1980 年代铸铁圆座 + 镀铬弯杆 + 墙裙绿降饱和搪瓷罩（内白），罩口朝东下照桌面，开关处、灯颈处磨损。
- 贴图集：PRP_ShiftDesk 2048，约 707 px/m。

## 和玩法的关系（没改玩家要看的东西）
- 点检单（谜题三 E3-5）仍用灰盒“玻璃板下的点检单”，夹在模型玻璃板里。**玻璃板材质 M_DSK_Glass 在 Unity 必须设成透明**（URP Lit Transparent，Alpha≈0.12），否则会把点检单挡住；manifest notes 里写了。
- 抽屉：follow DrawerBox（rigid）；highlight drawer → Drawer、desk_lamp → DeskLamp。
- hide_graybox：交班桌_桌面、桌腿、抽屉_盒、台灯_座、台灯_杆。交班本、点检单、对讲机、椅子不在本模型。

## 发现的灰盒问题（未改 Demo α 文件）
1. 台灯_座 / 台灯_杆 (25.95, 13.45) 和对讲机 (26.0, 12.7) 在桌面西沿 X 26.1 外面，悬空（WorkshopGraybox.cs:388–390）。模型台灯底座放回桌面 (26.2, 13.5)，灯罩伸到 X≈26.03，仍落在 desk_lamp 碰撞盒里；对讲机灰盒照旧悬空，见 `预览/机位B_*.png`。
2. 机位 B（N1，俯 15°，32mm，水平 36 mm 胶片，和 NodeCameraRig.VerticalFov 一致）下，交班桌只露在画面最下沿，交班本中心大约在画面下边线上（`预览/机位B_N1_交班桌_16点.png`）。同位置俯 35° 才把交班本、台灯放到画面中下部（`预览/机位B_补充_同位置俯35度.png`）。机位是否调整由协调者 / 用户决定。

## 验证
- `build_stats.txt`：每个部件三角数、贴图集密度、FBX 回读（重新导入后每个部件包围盒中心 / 枢轴与 .blend 对比，最大误差见文件，均 < 0.1 mm）。
- 独立校验脚本（导入 FBX，核对 manifest 里 follow / highlight / mirror_emission 的部件名都在 FBX 里、highlight 的交互 ID 都在 ContentDB.World.cs、hide_graybox 名字都在 WorkshopGraybox.cs）：全部通过。
- 预览：`预览/`（Cycles CPU 960×540，32 samples；灰色方块是不归道具组的灰盒占位）。
- **未验证**：Unity 里的导入朝向、材质（尤其透明 / 自发光）、跟随与高亮实际效果都没在 Unity 里跑过；没有写 C#，不涉及编译检查。

## 流程与复现
- 公共脚本：`Props/_common/props_lib.py`（建模小工具、调用 `Textures/lsb_bake.py` 的 `bake_atlas` 烘贴图集、贴字 / 贴花合成、复用 `export_fbx_unity.flatten` 导出、FBX 回读检查）；`gen_props_textures.py`（道具补充的可平铺贴图，输出到 `Props/_Textures/`）；`render_props.py`（预览）。
- 复现：`python3 build_ShiftDesk.py <输出目录>`（输出 .blend、.fbx、贴图集 4 张、build_stats.txt），预览：`python3 ../_common/render_props.py <各资产输出根目录> <预览目录> [视图]`。
- 导出：flatten 后按部件合并，部件只有位置、没有旋转；导出参数与 export_fbx_unity.py 相同（axis_forward −Z、axis_up Y、FBX_SCALE_UNITS，不用 bake_space_transform）。export_fbx_unity.py 本身没改。
- 贴图集：`<key>_Atlas_BaseColor / _Normal（OpenGL）/ _ORM / _MS`，材质名 `M_<key>_Atlas`（Unity 端 Stage3ArtMaterials 自动接）；其余 `M_*` 是纯色材质。
