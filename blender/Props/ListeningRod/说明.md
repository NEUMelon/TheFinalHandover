# 听针 · 说明

由 AI 辅助工具编写（Stage 3 道具组 3D 资产，2026-10-15）。数据来源：WorkshopGraybox.cs、ContentDB.World.cs / Puzzles.cs、WorldPresenter.cs、02_车间白盒规格_v0.1.md、01_圣经/02_美术圣经_v0.1.md、01_世界观圣经_v0.1.md。

## 资产

- 资产：`LSB_ENV_PRP_ListeningRod_v01`（Mid，预算 1k）。实测 **538 三角**，一个部件 ListeningRod。
- 造型（美术圣经 §6“长柄金属听棒 + 木柄，木柄被左手磨亮”；世界观圣经“听针，待核 K-12”）：胶木耳贴 Ø35 → 鼓形木柄 120 mm（中段“磨亮木”，老周左手握出来的包浆）→ 铜箍 → Ø6 钢针 300 mm，圆头。全长约 0.46 m。
- 灰盒里**没有**听针实体：它是工具（ToolId.Probe，按 1–4 切换），所以 hide_graybox 为空。manifest 给了一个默认摆放：平放在工具箱盖上，世界 (27.17, 0.2635, 12.24)，针朝东；manifest 只有 yaw，没做倾斜，针尖离盖面约 1.5 cm。也可以不摆，只在 CU1 特写当手持道具用——由协调者定。highlight toolbox_desk → ListeningRod（点工具箱取工具时一起亮）。
- 局部原点 = 木柄握持段中心轴线（手持时握点）。贴图集：PRP_ListeningRod 512，约 1,870 px/m。

## 验证
- `build_stats.txt`：每个部件三角数、贴图集密度、FBX 回读（重新导入后每个部件包围盒中心 / 枢轴与 .blend 对比，最大误差见文件，均 < 0.1 mm）。
- 独立校验脚本（导入 FBX，核对 manifest 里 follow / highlight / mirror_emission 的部件名都在 FBX 里、highlight 的交互 ID 都在 ContentDB.World.cs、hide_graybox 名字都在 WorkshopGraybox.cs）：全部通过。
- 预览：`预览/`（Cycles CPU 960×540，32 samples；灰色方块是不归道具组的灰盒占位）。
- **未验证**：Unity 里的导入朝向、材质（尤其透明 / 自发光）、跟随与高亮实际效果都没在 Unity 里跑过；没有写 C#，不涉及编译检查。

## 流程与复现
- 公共脚本：`Props/_common/props_lib.py`（建模小工具、调用 `Textures/lsb_bake.py` 的 `bake_atlas` 烘贴图集、贴字 / 贴花合成、复用 `export_fbx_unity.flatten` 导出、FBX 回读检查）；`gen_props_textures.py`（道具补充的可平铺贴图，输出到 `Props/_Textures/`）；`render_props.py`（预览）。
- 复现：`python3 build_ListeningRod.py <输出目录>`（输出 .blend、.fbx、贴图集 4 张、build_stats.txt），预览：`python3 ../_common/render_props.py <各资产输出根目录> <预览目录> [视图]`。
- 导出：flatten 后按部件合并，部件只有位置、没有旋转；导出参数与 export_fbx_unity.py 相同（axis_forward −Z、axis_up Y、FBX_SCALE_UNITS，不用 bake_space_transform）。export_fbx_unity.py 本身没改。
- 贴图集：`<key>_Atlas_BaseColor / _Normal（OpenGL）/ _ORM / _MS`，材质名 `M_<key>_Atlas`（Unity 端 Stage3ArtMaterials 自动接）；其余 `M_*` 是纯色材质。
