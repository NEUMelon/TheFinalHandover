## 资产

- 资产：`LSB_ENV_PRP_Lockers_v01`（Mid，预算 6k）。实测 **5,046 三角**（Lockers 3,840 / Locker_Zhou 612 / LockerDoor_Zhou 594）。
- 摆放：局部原点 = 六只一排的底面中心 → 世界 (32.9, 0, 17.6)，yaw 0；柜门朝南。每只 0.6 × 0.5 × 1.8，X = 30.9 … 34.9（白盒位置，柜间 0.2 m 空当照白盒保留）。
- 部件：Lockers（另外五只，关着）、Locker_Zhou（老周那只：空心柜体、上下两层隔板、两只挂钩、蓝灰工作帽）、LockerDoor_Zhou（枢轴 = 灰盒“老周柜门_铰链” (33.81, 0.9, 17.34)，follow WorkshopRefs.LockerDoor，mode rot；开门 = Y +105° 往南外开，预览里验证了方向）。
- 年代 / 造型：1983 技改时添置的钢板更衣柜，灰蓝漆（白盒同色系）、灰底漆，上下百叶、名牌插卡框、竖把手 + 挂锁扣、两道压筋、西侧铰链。磨损按动线：把手、挂锁扣、门下沿踢门处；老周那只把手最重。老周的名牌卡：发黄纸卡手写“周铁生”（世界观圣经人名口径）；其他五只名牌框空着（不编人名）。
- 柜内：手套、工牌套、合影、饭盒都是交互物，留在灰盒；隔板高度按它们放（下隔板上沿 1.215 = 手套底，上隔板上沿 1.575 = 饭盒底）。工作帽（事实链 E1-7“老周的搪瓷饭盒、工作帽”）放在上隔板西半边，避开饭盒。
- 贴图集两张：PRP_Lockers 2048（五只，约 313 px/m）+ PRP_LockerZhou 2048（老周那只 + 门，N2 正对，约 515 px/m）。
- 交互：highlight locker_zhou → Locker_Zhou、LockerDoor_Zhou。

## 注意 / 发现的问题（未改 Demo α 文件）
1. hide_graybox 写了“更衣柜”：灰盒的**父组也叫“更衣柜”**（WorkshopGraybox.cs:413），柜内交互物的渲染体都在它下面。只能隐藏名字精确等于“更衣柜”的方块自身的 Renderer，不能递归，否则手套、工牌套等会一起消失。
2. 工牌套 (33.86, 1.45, 17.2) 和建线合影 (33.82, 1.55, 17.3) 是按“门开着”摆的固定位置，门关着时穿出柜门外（Z < 17.33），模型柜门挡不住。建议把这两件挂到 LockerDoor 铰链下面跟门走。

## 流程与复现
- 公共脚本：`Props/_common/props_lib.py`（建模小工具、调用 `Textures/lsb_bake.py` 的 `bake_atlas` 烘贴图集、贴字 / 贴花合成、复用 `export_fbx_unity.flatten` 导出、FBX 回读检查）；`gen_props_textures.py`（道具补充的可平铺贴图，输出到 `Props/_Textures/`）；`render_props.py`（预览）。
- 复现：`python3 build_Lockers.py <输出目录>`（输出 .blend、.fbx、贴图集 4 张、build_stats.txt），预览：`python3 ../_common/render_props.py <各资产输出根目录> <预览目录> [视图]`。
- 导出：flatten 后按部件合并，部件只有位置、没有旋转；导出参数与 export_fbx_unity.py 相同（axis_forward −Z、axis_up Y、FBX_SCALE_UNITS，不用 bake_space_transform）。export_fbx_unity.py 本身没改。
- 贴图集：`<key>_Atlas_BaseColor / _Normal（OpenGL）/ _ORM / _MS`，材质名 `M_<key>_Atlas`（Unity 端 Stage3ArtMaterials 自动接）；其余 `M_*` 是纯色材质。
