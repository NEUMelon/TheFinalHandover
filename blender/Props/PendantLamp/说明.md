# 搪瓷灯罩 + 吊杆（18 盏） · 说明

由 Claude 编写（Stage 3 道具组 3D 资产，2026-10-15）。数据来源：WorkshopGraybox.cs、ContentDB.World.cs / Puzzles.cs、WorldPresenter.cs、02_车间白盒规格_v0.1.md、01_圣经/02_美术圣经_v0.1.md、01_世界观圣经_v0.1.md。

## 资产

- 资产：`LSB_ENV_LGT_PendantLamp_v01`（Mid，预算 0.8k / 盏）。实测 **690 三角 / 盏**（Lamp 420 / LampGlow 270），18 盏共 12,420。
- 摆放：局部原点 = 灯罩中心 → 世界 (x, 5.5, z)，x = 2, 6, 10, 14, 18, 22，z = 4.5, 9.0, 13.5（白盒规格 §4），18 个实例写在同一个 manifest。吊杆向上到 Y 9.0，顶上一块抱箍。
- 造型（美术圣经 §5“吊杆搪瓷灯罩白炽灯”，待核 K-11）：Ø0.45 深碗形搪瓷罩，外墙裙绿（降饱和）、内白，口沿卷边，口沿和棱上掉瓷露黑底（没人碰，所以只按棱边掉瓷，不做手磨）；铸铁灯头；吊杆 Ø20。
- 部件：Lamp（外罩 + 灯头 + 抱箍 = 贴图集；吊杆 = 纯色 M_LMP_Rod，3.4 m 长条放进贴图集会把其它部件的像素挤没）、LampGlow（罩内白搪瓷面 + 灯泡，材质 **M_LMP_Glow_On**）。
- 亮灭：mirror_emission 逐盏写了 LampGlow ↔ 灰盒“灯罩_X{x}_Z{z}”。灭的时候建议换成不发光的白搪瓷 #E8E4D8；Stage3ArtMaterials 给 _On 材质的自发光是交接灯暖橙 #F0A040×4，对钨丝灯偏橙偏亮，建议 2700K 暖白约 #FFD9A0、强度 2–3（协调者定）。
- hide_graybox：`灯罩_X*`、`吊杆`（精确名，天车“司机室_吊杆”不受影响）。注意 WorkshopRefs.Reindex 按“灯罩_X”前缀找灯罩渲染体，模型实例名用的是“吊灯_X…”，别改成“灯罩_X…”开头。
- 贴图集：LGT_PendantLamp 512，约 750 px/m（5.5 m 高，够用）。罩内法线朝内（已检查：罩内面法线 · 外向 = −0.77，外罩 +0.74），Unity 背面剔除下从下面能看到罩内。

## 验证
- `build_stats.txt`：每个部件三角数、贴图集密度、FBX 回读（重新导入后每个部件包围盒中心 / 枢轴与 .blend 对比，最大误差见文件，均 < 0.1 mm）。
- 独立校验脚本（导入 FBX，核对 manifest 里 follow / highlight / mirror_emission 的部件名都在 FBX 里、highlight 的交互 ID 都在 ContentDB.World.cs、hide_graybox 名字都在 WorkshopGraybox.cs）：全部通过。
- 预览：`预览/`（Cycles CPU 960×540，32 samples；灰色方块是不归道具组的灰盒占位）。
- **未验证**：Unity 里的导入朝向、材质（尤其透明 / 自发光）、跟随与高亮实际效果都没在 Unity 里跑过；没有写 C#，不涉及编译检查。

## 流程与复现
- 公共脚本：`Props/_common/props_lib.py`（建模小工具、调用 `Textures/lsb_bake.py` 的 `bake_atlas` 烘贴图集、贴字 / 贴花合成、复用 `export_fbx_unity.flatten` 导出、FBX 回读检查）；`gen_props_textures.py`（道具补充的可平铺贴图，输出到 `Props/_Textures/`）；`render_props.py`（预览）。
- 复现：`python3 build_PendantLamp.py <输出目录>`（输出 .blend、.fbx、贴图集 4 张、build_stats.txt），预览：`python3 ../_common/render_props.py <各资产输出根目录> <预览目录> [视图]`。
- 导出：flatten 后按部件合并，部件只有位置、没有旋转；导出参数与 export_fbx_unity.py 相同（axis_forward −Z、axis_up Y、FBX_SCALE_UNITS，不用 bake_space_transform）。export_fbx_unity.py 本身没改。
- 贴图集：`<key>_Atlas_BaseColor / _Normal（OpenGL）/ _ORM / _MS`，材质名 `M_<key>_Atlas`（Unity 端 Stage3ArtMaterials 自动接）；其余 `M_*` 是纯色材质。
