## 2. LT01 车床 Hero（`LSB_ENV_MCH_Lathe_LT01_v##`）

### 2.1 尺寸与原点

- 外形 2800 × 1000 × 1300 mm；导轨面 950；主轴中心高 1150；主轴箱 X 0–900（西端）。
- **局部原点** = 床身西端底面中心；摆放到世界 (8.0, 0, 11.0)，主轴轴线沿 +X，操作面朝南（−Z）。
- 白盒灰盒里 LT01 的体块位置不变，替换时按名字 `LT01` 对齐（见 §7 接入）。

### 2.3 预算

| 项 | 值 |
|---|---|
| LOD0 | 60–80k tris（美术圣经 §6） |
| LOD1 / LOD2 | 50% / 15%（LT02–04 背景车床直接用 LOD1 + 不同磨损遮罩） |
| 贴图 | 2 套 UDIM 等价：机身 4K + 小件 2K；Texel density ≥ 1024 px/m（Hero 特写处 2048 px/m） |
| 贴图通道 | BaseColor（含手绘笔触）、Normal（OpenGL → Unity 导入勾 Normal map）、ORM（R=AO, G=Roughness, B=Metallic；URP Lit 用 Mask 通道需在 Unity 端拆分或用 Shader Graph 读 ORM） |
| Detail | 笔触 Detail Map 1 张（512，平铺），URP Lit Detail Inputs |

### 2.4 年代叠层（材质图层顺序，Substance 或 Blender 均可）

按美术圣经 §4：L0 铸铁 → L1 1956 苏式灰绿（剥落处可见，待核 K-01）→ L2 1983 墙裙绿降饱和 15% → L3 L1 测点 → L4 1987 护罩凹痕 → L7 2025 传感器与新线 → 磨亮（手轮、手柄、L1 周围：曲率遮罩 + 低 Roughness）→ 包浆（AO + 污垢，手柄、导轨端）。

**磨损动线**：操作者站位 Z 10.1、右手摇溜板手轮、左手伸向主轴箱 → 手轮把手、变速手柄、主轴箱前上沿、L1 周围最亮；尾座端最少。禁止均匀做旧和无动线依据的划痕。

## 3. 继电器控制柜 Hero（`LSB_ENV_CTL_RelayCabinet_Old_v##`）

- 1000 × 600 × 2000 mm，底座 100；双开门；左门外交接状态板（4 灯，中心高 1600）；门锁一字锁芯（螺丝刀开）。
- 柜内 4 排 × 8 只继电器；**护罩联锁继电器 = 第 2 排左数第 3 个**，红胶布“护罩 87” + 白胶布“保留 08”（字样待用户确认 U-08）。
- 下部：端子排、1998 灰 PVC 线槽、2025 新线槽 + 扎带 + 二维码标签。
- 预算 30–40k tris；左右两台“新旧对照柜”复用同一套柜体，内部减配。
- 交接灯材质：亮 = 暖橙自发光（旧方式承担），灭 = 深灰（衡接手）；熄灭余辉 2700K → 暗 600ms（UI-DS §5.4）。灯珠做独立子物体 `HandoverLamp_1..4`，便于程序控制。

## 4. 16:00 正式灯光（URP 14）

| 光 | 设置 |
|---|---|
| 主光（太阳） | Directional，方位 235°（灰盒里是 `Quaternion.Euler(18, 55, 0)`：光从西南射向东北），高度 18°；色温 5000K；Soft shadows；直射光柱经**南墙高侧窗**（X 0–24，Y 3.5–6.0）落到 Z 8–16 |
| 天光 | Environment Lighting = Color 或 Gradient，降饱和晒图蓝；强度约 0.6 |
| 钨丝灯 | 6 排 × 3 盏，2700K；日景压暗到能看出灯丝即可；每排一组（逐排熄灯用） |
| 体积光 | URP 14 无内置体积雾：用**光柱网格 + 加色噪声 Shader**（每扇高侧窗一片，沿光线方向拉伸），配合粉尘 GPU 粒子 ≤2000；只在日景开 |
| GI | 烘焙 Lightmap（Progressive GPU）+ Light Probe Group；不依赖 APV |
| 后处理 | ACES、Film Grain 0.1、轻 Bloom（阈值高，只让钨丝灯和光柱边缘发光）；不用色差、强暗角、镜头光晕 |
| 色比验收 | 日景：蓝绿灰 72% / 暖黄 12% / 安全黄 5% / 黑 9% / 冷白 1% / 红 1%（美术圣经 §2） |

灯光拆解图：同一机位分别只开主光、天光、钨丝灯、体积光、自发光各渲一张 + 合成一张。

## 7. 引擎接入约定（给人工-3D 和程序）

- FBX：Y-up，单位 m，Apply Transform；子物体名与 §2.2 部件名一致。
- 放到 `Assets/LSB_Art/Env/<资产名>/`（新目录，不碰 `Assets/LSB/`），Prefab 名 = 资产名。
- 替换方式：Stage 3 插件按名字把灰盒体块隐藏、在原位实例化 Prefab（见 `02_母项目VS/stage3_addon/README.md`），不改灰盒生成脚本；交互碰撞体沿用灰盒的。
- 每完成一步（白模 / 中模 / 高模 / 贴图 / 引擎）在同一机位截一张图，存 `20_场景地编/过程/`，文件名 `LSB_ENV_Process_<步骤>_v##.png`。这是展板流程区的素材，必须真实。
