## 怎么重建

```
pip install bpy==5.1.2
python3 Textures/gen_textures.py Textures 1024           # 可平铺漆层 / 铸铁 / 机加工钢 / 磨亮金属 + 剥落遮罩
python3 LT01/build_LT01.py <out>                         # 建模 → <out>/…_v02.blend
python3 LT01/bake_LT01.py <out> 4096                     # 按动线合成贴图集 → Textures/Atlas/LT01_Atlas_*
python3 export_fbx_unity.py <out>/LSB_ENV_MCH_Lathe_LT01_v02.blend <out>/LSB_ENV_MCH_Lathe_LT01_v03.fbx   # v03 部件扁平化导出
```
继电器柜同理（`RelayCabinet/build_RelayCabinet.py`、`bake_RelayCabinet.py`，2048）。LT01 4K 合成在这台云端机器上约 70 分钟。

## 做旧怎么来的（规格 §2.4“禁止均匀做旧”）

每个像素的磨损度 W = 基础值 + 棱边（曲率）+ 手常碰的位置 + 离地 15 cm 踢碰区；剥落面积随 W 增减，手常碰处露铁磨亮、粗糙度降低。
- LT01 手碰点：溜板箱手轮（最重）、中拖板手轮、变速手柄、主轴箱前上沿、L1 测点、进给手柄、尾座锁紧（最轻）；1987 凹痕处漆皮崩裂露铁，**不磨亮**。
- 继电器柜手碰点：右门把手、左门一字锁、中缝推门处、门下沿。
- 坐标、半径、强度写在 `bake_LT01.py` / `bake_RelayCabinet.py` 的 `TOUCH` 表里，改了重跑即可。

## 进 Unity

1. 已放好：`Assets/LSB_Art/Env/LSB_ENV_MCH_Lathe_LT01/…_v03.fbx`、`…/LSB_ENV_CTL_RelayCabinet_Old/…_v03.fbx`（v02 已从工程删除；用户本机需手动删 v02，见增量包 2 说明）、`Assets/LSB_Art/Env/Textures/*_Atlas_*`。
2. 菜单 **LSB → Stage3 → 建立 3D 资产材质**：建 URP Lit 材质并替换 FBX 自带材质。
3. 菜单 **LSB → Stage3 → 摆放 3D 资产**（`Stage3PlaceArt.cs`）：自动摆 LT01 到 (8.0, 0, 11.0)，主轴箱在西、操作面朝南；旧柜到 (26.1, 0, 0)，柜门朝北。朝向按部件位置算（上 = 床脚→床身 / 柜体→交接状态板；水平 = 主轴箱→尾座 / 柜体→柜门），镜像时会出黄字警告。
4. 可选：**LSB → Stage3 → 切换灰盒（车床、旧柜外壳）** 只在编辑器里隐藏重叠灰盒。
5. 接玩法（10-15，`Stage3ArtBinder.cs`）：Play 时自动隐藏被替换的灰盒，模型的卡盘、两扇柜门、4 盏交接灯跟着灰盒状态走；碰撞盒和交互判定仍是灰盒的，逻辑层没改。**还没在 Unity 里试玩验证**。
