全部用 rigid 跟随。`WorldPresenter.cs:218` 的摆动其实是**绕 Z 轴转、沿 X 方向摆**：`FromToRotation(down, (sinθ, −cosθ, 0))`。规格里写的“摆动轴为 X 方向”指的是摆动方向。部件做 rigid 跟随，不受这一点影响。洒水时灰盒会执行 `MugWater.SetActive(false)`，模型水面要跟着隐藏（已写进 manifest 的 notes）。

## 造型依据和我做的取舍

- **尺寸**：轨顶 Z 7.0，车轮踏面落在轨顶上；端梁的 Y 范围是 0.62–1.05 和 16.95–17.38，避开柱子内侧面 0.6；小车顶最高 8.78，在屋架下弦 8.85 以下；司机室按灰盒做，1.4×1.8×1.4，中心 (0.2, 5.6, 2.0)。依据：车间白盒规格 §2/§3，WorkshopGraybox.cs:266–293。
- **主梁位置**：灰盒的主梁在桥架局部 X 0 和 −0.9，但摆动轴在 X 0，正好压在一根主梁里面。真天车的钢丝绳是从两根主梁中间垂下来的，所以模型把两根主梁对称放在 X ±0.55，比灰盒整体往东挪了 0.45 m。
- **年代特征（1950–80 年代国营厂）**：主梁是铆接箱形梁，两端变截面；腹板外侧有加劲板和铆钉行；走台上是集中驱动电机，经长传动轴连到两端减速箱；端梁上有橡胶缓冲器；司机室吊在梁下，里面有两台凸轮控制器和木座椅；地板上开了观察窗；司机室底下挂天车铃，拉绳穿过地板接到木把手。
- **颜色**（美术圣经 §2）：安全黄 #F2C200 只出现在吊钩和警示斜纹上，斜纹贴在主梁外腹板跨中、梁底变截面段、端梁、缓冲器座、导绳器和钩头侧板上。梁体和司机室用设备漆，即墙裙绿降饱和后的 #66746A。漆面掉漆先露出铁红底漆 #7A4A3A，再露出铁。灰盒里梁和司机室是整块安全黄，按美术圣经，安全黄只能用在吊钩和梁的警示斜纹上，所以改了。
- **2026 自动化套件**（美术圣经 §6，`待核 K-05`）：南端梁东车轮轴端装了编码器，卷筒轴端装了编码器，小车东南角装了冷白状态灯（`M_CR01_StatusLED_2026`）。
- **吊钩**：钩头是两块侧板加动滑轮，侧板涂黄黑斜纹；钩身用锻钩造型，截面从圆形渐变成梯形，钩尖收细，涂安全黄。吊环穿在钩座里，3 根钢丝绳吊索挂一个 Ø0.22 的圆吊盘。**吊盘和灰盒不一样**：灰盒是 0.45 的方板，从 N8 的仰角（约 36°）看上去会把缸整个挡住，所以缩成圆盘。缩小以后，从 N8 也只能看到缸口附近一点（见下文“未验证 / 风险”）。
- **钢丝绳**：截面是扭转的六边形，平直着色后会出现斜向的股纹。两段绳的 Y 坐标是 ±0.13：卷筒到摆动轴这段算静态，放在小车部件里；摆动轴到钩头动滑轮这段放在 Rope 部件里，长 2.75 m。摆长仍然是灰盒的 4.0 m。
- **搪瓷缸**：美术圣经 §6 写的是“白底、口沿蓝边、掉瓷点”，**没有写红字**，所以模型没加字。尺寸是外径 Ø0.10、高 0.12，有卷边，口沿是蓝色，把手是扁带。吊钩上那只缸的水面比口沿低 5 mm，也就是“满水”。司机室那只旧缸复用同一个造型，口沿磕掉一块瓷，依据 ContentDB.Puzzles.cs:83 的“口沿磕掉一块瓷”。釉面未掉瓷的地方粗糙度设成 0.12，是烘焙后改的。

## 未验证 / 风险

- 没有在 Unity 里导入过，下面这些都没核对：轴向、材质自动建立、跟随、水面隐藏、状态灯自发光。
- **按看板的精确参数，机位 D 里吊钩在画面上沿，缸大半被吊盘挡住**，只看得到盘底和钩下部（见 `预览/CR01_机位D_N8_夜.png`）。要想让缸和水面进画面，得让机位 D 的仰角或位置和这个造型配合起来调。这个由协调者 / 用户决定，我没改看板。
- 司机室没有装玻璃，地板观察窗也没有，所以窗洞是空的。
- 搪瓷缸、吊钩这类 Hero 近景，在 Unity 光照下效果怎样还没验证。
