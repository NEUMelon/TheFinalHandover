## 2. 与灰盒碰撞体的关系

灰盒里 `Span()` 默认 `blocker = true`：地面、各面墙、柱、屋面、天窗顶、附房墙 / 吊顶、控制间隔断下段 / 上框 / 门框上、西大门都带 BoxCollider。模型只替换渲染，所以这些地方**按灰盒同一组角点建模**。

检查（`check_env.py --colliders`）：在 54 个 blocker 方块露出的表面上撒点，量到模型表面的最近距离——除 3 块外全部 0 mm；`西墙_南段`、`西墙_北段`、`附房_东墙` 各有 28–36 个点 125 mm，原因是模型把墙角补到了 −0.25 / 18.25（灰盒墙角那里是空的），点在模型墙体里面，不是模型缺了一块。

**和灰盒不一样的地方（都没有碰撞体，〔派生〕）**：
- 墙顶从 9.0 封到 10.6：灰盒墙顶 9.0、屋面底 10.4，中间一圈 1.4 m 的缝会漏光。
- 天窗两端封板（X 0 / 24）、天窗挑檐封边。
- 屋架：灰盒是下弦 + 两根斜上弦；这里做成平行弦桁架（下弦中心 9.0，上弦顶 10.4 托屋面板，节间 1.45 m，竖杆 + 斜腹杆 + 节点板），与平屋面（灰盒 10.4–10.6）对得上。规格写“屋脊 10.5”，屋面板中心正好 10.5。
- 吊车梁：T 形混凝土梁 6.6–6.87 + 钢轨（轨顶 7.0，Z 0.75 / 17.25，与天车工人确认端梁车轮压在 7.0）。
- 牛腿做成下斜面（灰盒是方块）。

## 6. LT02–LT04（Mid）

`build_LatheMid.py` 读 `../LT01/build_LT01.py` 源码（**只读**，没有改 LT01/ 下任何文件），在内存里替换后执行：
- 去掉剧情细节：R1 传感器、2025 新线 + 扎带、L1 漆圈 / 样冲点、护罩凹痕（护罩改成无开孔的 50 mm × 10° 粗网格）；
- 减面：圆柱段数 × 0.55（最少 8 段）、倒角 ≤ 2 段、手轮轮缘 28×8；
- 原脚本的保存 / 导出段不执行。

结果 13,976 三角面（LT01 39,556）。贴图：用 `Textures/lsb_bake.py` 同一套“磨损动线”配方（手碰点去掉 L1 与凹痕）重新烘 2048² `LSB_ENV_MCH_Lathe_Mid_Atlas`（约 321 px/m）。导出时合成一个部件 `LatheMid`（没有会动的部件）。三台用同一张贴图，磨损一模一样（没做每台不同的磨损遮罩）。

实例：LT02 (2.0, 0, 11.0)、LT03 (14.0, 0, 11.0)、LT04 (20.0, 0, 11.0)，yaw 0（= 灰盒 cx − 1.4；原点 = 床身西端底面中心，同 LT01）。

## 8. 发现的问题（给协调者 / 灯光）

**16:00 光柱照不到 LT01**：按规格的太阳（方位 235°、高度 18°，灰盒 `Euler(18, 55, 0)`）与南墙高侧窗（窗台 3.5、窗顶 6.0），光线每向北走 1 m 下降 tan18° / cos55° ≈ 0.57 m。从窗进来的直射光落地在 Z ≈ 6.2–10.6；在 LT01 主轴箱顶的高度（1.3 m）只到 Z ≈ 3.9–8.3。LT01 在 Z 10.5–11.5，**不在直射光里**——规格 §2“落点约 Z 8–16（覆盖 LT01）”和关键帧 A“光柱落在 LT01 主轴箱上”按这组数算不成立，光主要落在主通道和两条黄线上。这是规格 / 灯光的问题，模型按规格做，没改窗的尺寸。

## 9. 怎么重建

```
python3 gen_env_textures.py                      # → Textures/LSB_ENV_BLD_*（约 1.5 分钟）
python3 build_LatheMid.py LatheMid 2048          # LT01 减配 + 烘贴图集（约 10 分钟）→ LatheMid/…_v01.blend、Textures/LSB_ENV_MCH_Lathe_Mid_*
python3 build_ENV.py Workshop                    # → Workshop/LSB_ENV_BLD_Workshop_v01.blend、LSB_ENV_BLD_Glass_v01.blend
python3 export_env.py Workshop/LSB_ENV_BLD_Workshop_v01.blend Workshop/LSB_ENV_BLD_Workshop_v01.fbx
python3 export_env.py Workshop/LSB_ENV_BLD_Glass_v01.blend Workshop/LSB_ENV_BLD_Glass_v01.fbx
python3 export_env.py LatheMid/LSB_ENV_MCH_Lathe_Mid_v01.blend LatheMid/LSB_ENV_MCH_Lathe_Mid_v01.fbx --single LatheMid
python3 check_env.py Workshop/LSB_ENV_BLD_Workshop_v01.blend Workshop/LSB_ENV_BLD_Workshop_v01.fbx --colliders
python3 render_preview.py Workshop/LSB_ENV_BLD_Workshop_v01.blend LatheMid/LSB_ENV_MCH_Lathe_Mid_v01.fbx ../LT01/LSB_ENV_MCH_Lathe_LT01_v04.fbx 预览 A,E,F,mid 32
```
