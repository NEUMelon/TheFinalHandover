## 做什么

熄灯本身还是 Demo α 的 `WorldPresenter` 来做（`SetLamp`、`SetRow`、`SwitchOff`：主轴 1.5 s 降速，然后 X22 → X2 每排 0.6 s）。本组件在它关灯之后叠一层“灯丝冷却”：

| 触发 | 余辉 | 依据 |
|---|---|---|
| `Ev.LampOff`（规则确认的同一帧，交接状态板第 N 盏） | 2700K → 暗，**0.6 s** | UI-DS §5.4 1400ms 行 |
| 结局 `EndingStep.LightsOut`～`Siren` 期间，检测到某排 `LampRows[r]` 的 Light 从开变成关 | 2700K → 暗红，**1.5 s** | 看板 Shot E、美术圣经关键帧 C ② |
| `EndingStep.Silence`、`Siren` | 西大门上方一盏冷绿白应急灯，强度 0.2，范围 6 m；进入 `HengBoot` 后 0.25 s 淡出 | 美术圣经 §7“应急灯”、关键帧 C ③。**位置 (0.8, 4.8, 8.5) 是派生的** |

余辉曲线（Unity 和样片用的是同一套）：u = t / 时长；色温 K = 800 + 1900·e^(−3.2u)；亮度 b = 0.6·e^(−6u) + 0.4·(1−u)^1.5；颜色用黑体近似（Tanner Helland）。

## 怎样不和别的脚本冲突（协调者要求的点）

- **不碰原渲染体的 sharedMaterial。** 给熄灭的灯罩或交接灯套一个子物体“余辉外壳”：网格相同，以网格包围盒中心放大 1.5%，材质是 `LSB/AfterglowShell`，颜色每帧通过 **MaterialPropertyBlock** 写到外壳上。所以 WorldPresenter 每次 `SetRow`、`SetLamp` 换材质，Stage3ArtBinder 每帧根据灰盒灯是否发光给模型切亮 / 灭材质，都照常进行，互不覆盖。
- 外壳只套在**当时可见**的渲染体上。灰盒交接灯被 Stage3ArtBinder 隐藏时，余辉落到模型部件 `HandoverLamp_1..4` 上（在 `LSB_Stage3_美术资产` 下按名字查找，与 Binder 的命名一致）。
- 另外加一盏临时点光源（来自对象池）：灯排在该排 Light 的位置，强度 = 原强度 × 0.55 × b^1.5，范围 × 0.6；交接灯在灯的包围盒中心，强度 0.6，范围 0.6 m。
- 衡启动时 WorldPresenter 会把灯排 Light 重新打开（冷白）。如果还有余辉没结束，它会立刻让位。
- 读档或新游戏（`PhaseChanged` 的 load / new）不播余辉，直接用 WorldPresenter 摆好的状态。

## 接入

1. 把 `LightsOutAfterglowFx.cs` 和 `LSB_AfterglowShell.shader` 跟其他 Stage 3 文件一起拷进工程，不需要手动挂组件。
2. 将来换正式灯具模型时，在 Binder 里调用 `LightsOutAfterglowFx.RegisterRowRenderer(row, 灯泡渲染体)` 就能把余辉落到模型上（row 0 = X2 … 5 = X22）。
3. 关掉：启动参数 `-lsbNoStage3Fx`（与记忆显影共用）。找不到 Shader 时只保留点光源，Console 会打一条警告。

## 验证过的 / 没验证的

- ✅ `bash 02_母项目VS/stage3_addon/tools/compile_check.sh`：Build succeeded（0 错误）。
- ✅ 样片在 Chromium（Playwright）里能渲染，关键帧 PNG 就是从样片截的。
- ✅ 机位核对：N9 的俯仰是 0°、焦距 28mm（`ContentDB.World.cs:40`），NodeCameraRig 按 36mm 片幅宽换算 FOV。照此计算，**X22、X18 两排灯在画面上沿之外**，镜头里只能看到它们照在地上的光；能直接看到灯罩余辉的是 X14 → X2。如果 Shot E 要让第一排余辉入画，需要另外给 SH-C 加仰角（由协调者或美术决定，这里没改）。
- ⚠ 发现：Demo α 灰盒的夜景以环境光为主（ambient 0.08，对比点光 1.5/d²，灯下地面只得到约 0.06），所以在 Unity 里熄灯时**地面亮度变化很小**，主要能看到的是灯罩。样片的亮度按“环境光 ×0.35、点光 ×6”示意，是目标气氛，**不代表灰盒实际观感**。
- ❌ **没在 Unity 里运行过**：外壳会不会和灯罩 Z-fighting、URP 下加色外壳的实际亮度、MPB 是否生效、余辉光源的亮度，都要在本机 Unity 2022.3 里看一遍。
- ❌ Shader 没编译过。
- 声音：灯排熄灭时 WorldPresenter 已经播放 `lamp_off`，交接灯熄灭由 RuleCardView 播放 `lamp_off`，本组件不发声，符合声音圣经“无数字声”。
