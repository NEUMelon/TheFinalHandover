# 记忆显影（LSB_MemoryDevelop）接入说明

> 派生自 00_主项目文档 v1.1 §6.8 VFX、美术圣经关键帧 B、声音圣经 §2.8。编写 2026-10-15。
> 源文件在 `02_母项目VS/stage3_addon/Assets/LSB_Stage3/`（协调者统一拷进 Demo α 工程，本说明不改 demo_alpha）。
> **验证状态（如实）**：Shader v02 用 DXC 1.8 按 D3D11 / Vulkan / Metal 平台宏、对 URP 14.0.12 头文件（GitHub `Unity-Technologies/Graphics` 分支 2022.3/staging，package.json 版本 14.0.12）编译通过；C# 对 Unity 2021.3 参考库编译通过。**两者都没有在 Unity 2022.3 编辑器里编译或运行过**。Windows 上 Unity 用 FXC 编 D3D11，DXC 通过不等于 FXC 通过，以第一次导入后的 Console 为准。

## 2. 接入步骤

1. 把 `stage3_addon/Assets/LSB_Stage3/` 整个拷进 `UnityProject/Assets/`（与 README 相同），等编译。
2. 看 Console：
   - Shader 有红字 → 把整段报错发回来（会写明行号，行号对的是 `.shader` 文件）。
   - 选中 `LSB_MemoryDevelop.shader`，Inspector 里应显示无错误、SRP Batcher “compatible”。
3. 遮罩导入设置：`Stage3KeyShots.cs` 会把 `MemoryMasks` 里的图设为非 sRGB、无 Mipmap；手动导入的话也要这样设（sRGB 关、Mipmap 关、Wrap Clamp）。
4. Play，走到谜题三用手电照护罩凹痕：
   - 静音 2 秒期间：画面四周慢慢变暗（现在由 Shader 的 `_Dim` 画，光锥里面不暗）；
   - 声音进来 0.8 秒后，画面**中心偏左**的光锥里暖黄网点聚合成两个剪影，年份“一九八七”在光锥右上；
   - 停 2 秒后网点缩小、上浮、散去；左下角标签写“Stage 3 记忆显影 v02（m1987 遮罩为占位）”。
   - 点一下或按 Esc：剪影先补满再溶解（和 Demo α 灰盒一致）。
5. 谜题四播完磁带触发 m1998：停 3.6 秒。
6. 关掉：启动参数 `-lsbNoStage3Fx`，或删掉 `MemoryMasks` 里对应的图（没有遮罩就不接管，Demo α 灰盒照常）。

## 3. 审查记录（URP 14 / Unity 2022.3 写法，逐项）

| 项 | v01 写法 | 结论 | v02 |
|---|---|---|---|
| include 路径 | `Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl` | 正确（URP 14 就是这个路径，已用 14.0.12 头文件核对） | 不变 |
| SubShader Tags | `RenderPipeline=UniversalPipeline`、`Queue=Transparent+50`、`RenderType=Transparent` | 正确 | 加 `PreviewType=Plane`（只影响 Inspector 预览） |
| Pass LightMode | `UniversalForward` | 正确（URP 透明队列会画这个 LightMode） | 不变 |
| 混合 / 深度 | `Blend One OneMinusSrcAlpha`、`ZWrite Off`、`ZTest Always`、`Cull Off` | 正确：输出是预乘 alpha，盖在一切之上 | 不变 |
| CBUFFER | 全部材质属性在 `UnityPerMaterial` 里 | 正确（SRP Batcher 兼容） | 新增 `_ConeRect`、`_Dim` 也放进去 |
| 纹理宏 | `TEXTURE2D` / `SAMPLER` / `SAMPLE_TEXTURE2D(_LOD)` | 正确 | 采样坐标加 `saturate`：PNG 默认 Repeat，光锥边缘不卷到对边 |
| 函数名 | `Hash(float2)` | **风险**：Core.hlsl → core `Common.hlsl` → `Random.hlsl` 已有 `float Hash(uint)`。HLSL 允许重载，DXC 实测能编，但一旦传进整数会调到库里那个 | 全部辅助函数加 `LSB_` 前缀 |
| 字面量 | `smoothstep(0, 0.3, x)` 等整数字面量 | 能编（隐式转换），FXC 可能报精度 / 转换警告 | 全部改浮点 |
| `_Time` | 来自 `UnityInput.hlsl` | 正确 | 不变 |
| UI 用途 | 不是 UI 材质，是画在世界空间四边形上 | **不需要** uGUI 的 `_MainTex`、Stencil、`_ClipRect`；UI Toolkit（2022.3）不能给 VisualElement 挂自定义 Shader，所以没有走 UI | 在文件头注明。若以后要放到 uGUI RawImage 上，需要另加 Stencil / ColorMask / `_MainTex` / 顶点色，不能直接用 |

**结论（如实）**：逐行审查 + DXC 旁证编译，**没有找到会让 v01 编译失败的地方**。v01 的问题在画面上而不在编译上（见 §4）；v02 的改动是“降风险 + 修画面”，不是修编译错误。是否真能在 Unity 里编过，仍要看第一次导入。

## 4. 驱动脚本 MemoryDevelopFx.cs 的问题与修改

| # | v01 问题 | 影响 | v02 |
|---|---|---|---|
| 1 | 四边形放在画面正中、大小 = 光锥 | UI 的光锥（`.mem-cone`，1920×1080 上 left 380 / top 150 / 720，即中心偏左）和年份字在左，网点却在正中，两者错开 | 四边形铺满视野；每帧从 UI 的 `.mem-cone.worldBound` 换算出光锥中心和直径传给 `_ConeRect`；UI 读不到时用 1920×1080 的固定值 |
| 2 | UI 的 `.memory.in`（rgba(4,8,14,0.42) 黑）是 UI Toolkit 覆盖层，画在 3D 之上 | 世界空间的网点被压暗 42%，比网页样片暗一截 | 接管期间把 `.memory` 的底色清掉，改由 Shader 的 `_Dim` 在光锥外压暗（同样 0→0.42、2 秒渐入），网点画在压暗层上面 |
| 3 | 跳过时只把溶解提前 | 若在聚合前跳过，Demo α 灰盒是“剪影先满再散”，Stage 3 版什么都不出现 | 跳过时把聚合补满再溶解 |
| 4 | `Shader.Find` 只判空 | Shader 编译失败时（粉色）仍会接管 | 加 `shader.isSupported` 判断，失败就沿用 Demo α 灰盒并打警告 |

编译检查：`bash 02_母项目VS/stage3_addon/tools/compile_check.sh` → `Build succeeded.`（2026-10-15）。
