## 1. 坐标系与单位

- 单位：米。Unity 1 unit = 1m。
- 原点：车间西南角室内地面（0, 0, 0）。**X 轴向东**（沿 36m 长边），**Z 轴向北**（沿 18m 跨），Y 向上。
- 朝向：长轴东西向；南墙 Z=0，北墙 Z=18；西山墙 X=0（车间大门），东端 X=36。
- 太阳：16:00 来自西南（方位约 235°），高度角约 17–20°（按虚构城市 40°N、10 月中旬计算值）。
