## 1. 流程

```
[S0 选择测点] L1 / R1 两个按钮（在车床主轴箱示意图上）
      │
[S1 播放]  选中测点 → 播放该测点的声音（循环 6s）+ 衡信号条（谜题一）
      │     可随时切换 L1/R1；有“并排对比”按钮
      │
[S2 时频图] 打开时频图（谜题二）：播放头同步滚动；L1 的每声咔哒对应竖条闪亮
      │
[S3 框选 / 比较]
      │   谜题一：在两条信号条中点选“更清楚的一侧”
      │   谜题二：在 L1 时频图上拖框框出冲击条纹；在 R1 边频指示上选“正常 / 异常”
      │
[S4 三联确认] 三格各 3 选项 → 按“确认”章
      │   错误 → 规则冲突 + 仿真声音 → 回到 S4（已选保留）
      │
[S5 Rule Card 生成] 经验规则卡（6 字段）+ 交接状态灯熄灭（灰盒用一个方块变暗）+ 等级 +1
```

纸面原型（阶段 1）：用打印卡片 + 手机播放音频走一遍 S0–S5，主持人扮演衡。
数字原型（阶段 2 第一周）：Unity 单场景，不需要车间。

## 3. 假数据格式

### 3.1 音频生成（离线 Python 脚本，团队自写）

| 文件 | 内容 | 参数 |
|---|---|---|
| `L1_normal.wav` | 齿轮嗡（620Hz + 谐波，−18dB）+ 2–4kHz 带通冲击，每 0.294s 一次（约 3.4 次/秒），冲击衰减 15ms | 48kHz，6s 循环 |
| `R1_normal.wav` | 齿轮嗡（620Hz，−6dB）+ 正常低幅边频 + 冲击（−30dB，几乎不可闻） | 同上 |
| `L1_wrong_gearfix.wav` | “换完齿轮后”的仿真：咔哒仍在 | 同 L1_normal，嗡声略变 |
| `R1_gearwear.wav` | 齿轮磨损仿真：边频增强 + 调制 | 用于干扰项反馈对比 |

### 3.2 时频图数据（JSON + PNG）

```json
{
  "id": "LT01_L1_normal",
  "audio": "L1_normal.wav",
  "duration_s": 6.0,
  "freq_max_hz": 8000,
  "time_bins": 600,
  "freq_bins": 256,
  "image": "LT01_L1_normal_spec.png",
  "db_range": [-80, 0],
  "annotations": {
    "resonance_band_hz": [2000, 4000],
    "resonance_band_label": "本机共振带（2026 复测）",
    "impacts_s": [0.12, 0.414, 0.708, 1.002, 1.296, 1.59, 1.884, 2.178, 2.472, 2.766, 3.06, 3.354, 3.648, 3.942, 4.236, 4.53, 4.824, 5.118, 5.412, 5.706],
    "gmf_hz": 620,
    "sideband_spacing_hz": 15,
    "sideband_index": 0.18,
    "sideband_threshold": 0.35
  }
}
```

- `image`：由脚本用 STFT（窗长 1024、跳步 80）生成的灰度 PNG，Unity 中按 `C-Sys` 着色。
- `impacts_s`：冲击时刻，用于播放头同步闪亮和框选判定。
- `sideband_index < sideband_threshold` 表示边频正常（R1 显示绿色正常区）。

### 3.3 信号条数据（谜题一）

```json
{ "L1": { "bearing": 0.72, "gear": 0.28 }, "R1": { "bearing": 0.06, "gear": 0.94 } }
```

### 3.4 规则卡数据

```json
{
  "rule_id": "ZHOU_CLICK",
  "source": "周铁生，1983 年设备记录批注；2026 年林小满复测",
  "measurement_point": "LT01 主轴箱左端 L1",
  "feature": "本机约 2–4kHz 结构共振带内的周期冲击",
  "binds": ["LT01_SPDL_BRG_RR_IMP_ALM", "LT01_GB_GMF_SB_IDX"],
  "status": "DRAFT"
}
```

`ZHOU_LEFT`：source“周铁生，1983 年测点示意页；2026 年衡对比复核”〔派生〕；measurement_point“LT01 主轴箱左端 L1”；feature“对主轴后轴承信噪比高于 R1”；binds `LT01_SPDL_BRG_RR_VIB`。

## 4. 判定规则

### 4.1 框选（谜题二）

| 条件 | 判定 | 反馈（衡日志，≤40 字） |
|---|---|---|
| 框的频率范围与 2–4kHz 重叠 ≥60%，且框内包含 ≥3 个 `impacts_s`，且不包含 620Hz | 正确 | `已标记：周期冲击 ×N，间隔 0.29s。` |
| 框包含 620Hz 线 | 偏差 | `框内混入齿轮啮合线。请缩小频率范围。` |
| 包含冲击 <3 个 | 偏差 | `冲击样本不足。请框得更长一些。` |
| 频率重叠 <60% | 偏差 | `框选区域不在冲击频带内。` |

偏差不计错误，不触发规则冲突；连续 3 次偏差触发对应的一级提示。

### 4.2 比较（谜题一）

点选信号条：选 L1 → 正确；选 R1 → `R1 轴承成分 6%，不可读。`

### 4.3 边频判断（谜题二）

选“正常” → 正确；选“异常” → 衡播放 `R1_gearwear.wav` 与 `R1_normal.wav` A/B 对比，日志 `当前边频指标 0.18，低于阈值 0.35。`

### 4.4 三联

三格正确答案与干扰项见事实链。错误：日志 `规则冲突`，播放对应仿真声音 3s，格子抖动；已选保留，不重来。

## 5. UI 状态

| 状态 | 进入条件 | 可用操作 | 显示 |
|---|---|---|---|
| S0 待选测点 | 进入特写 | 选 L1 / R1 | 示意图两个点闪烁 |
| S1 播放中 | 选测点 | 切换测点、并排对比、打开时频图 | 当前测点高亮；音量表 |

## 6. 试玩验证指标

对象：5–8 名未接触项目的同学（与交互小组第 1 轮可用性测试合并，v1.1 §9.3）。

| 指标 | 采集方式 | 通过线〔派生〕 |
|---|---|---|
| 任务完成率（不用三级提示完成谜题一 + 二） | 日志 | ≥80% |
| 谜题二完成时长中位数 | 日志 | ≤4:00 |
| 框选首次正确率 | 日志 | ≥60% |
| 三联错误次数中位数 | 日志 | ≤2 |
| 声音区分：咔哒 vs 嗡 盲听正确率 | 测后小测 | ≥90% |
| 理解检验：能用自己的话说出“为什么是 L1”“咔哒说明什么” | 测后访谈 | ≥4/5 人说对 |
| “本机特征”误解率：认为“咔哒一定是轴承坏了（所有机器）” | 测后访谈 | ≤1/5 人；超出则改字幕与规则卡 Feature 文案 |
| 规则卡 Source 字段被注意到 | 访谈：“这条规则是谁的？” | ≥4/5 人答出老周 |
| 主观：是否有“我听出来了”的时刻 | 1–5 分 | 均值 ≥4 |

日志 CSV 字段：`player_id, timestamp_ms, state, action, target, result, hint_level`。
