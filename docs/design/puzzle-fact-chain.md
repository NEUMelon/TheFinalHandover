## 0. 证据分级与通用规则

| 等级 | 定义 | 设计要求 |
|---|---|---|
| **必要证据**（N） | 缺了它，玩家**无法**仅凭现有信息推出三联中的某一格 | 不可错过：放在动线必经处，或由衡日志主动指向；拾取后自动贴入交班本 |
| **引导证据**（G） | 不参与推理，但把玩家带向必要证据 | 可错过，错过时由一级提示补上 |
| **氛围证据**（A） | 只提供情感与年代质感 | 可错过；不得包含与推理相矛盾的信息 |

通用规则（来自 v1.1 §3.4）：三格都正确才能确认；填错 → 衡报“规则冲突” + 仿真播放“机器听起来不对”的声音，不扣分不重来；每 90 秒至少一次动手操作；单屏文字 ≤60 字；所有声音都有时频图或字幕。三联板每格 3 个选项（1 正确 + 2 干扰），选项来自已拾取证据，未拾取的证据对应选项显示为灰色“待取证”。〔派生〕

提示阈值：一级 90 秒 / 二级 180 秒 / 三级 300 秒（自上一次有效操作起算），可关闭。

## 2. 谜题一“左手”（教学）

| 项 | 内容 |
|---|---|
| 区域 | 更衣休息室 → 机加工区 LT01 |
| 剧情内时刻 | 16:00–16:30 |
| 预计游玩时间 | 1:50（v1.1 §5.3 的 0:40–2:30），首次游玩含提示上限 2:30 |

**1. 衡最初的问题**
衡在主轴箱右端装了临时传感器（R1），用来监测主轴后轴承，但信号几乎全是变速齿轮的声音，读不出轴承状态。衡日志：
`[16:04] MON > LT01 主轴后轴承：R1 信号以齿轮啮合为主，轴承特征不可读。请确认正式测点。`

**2. 玩家看到 / 听到的异常**
在 R1 贴听针：只听到一片“嗡”。衡的 R1 信号条：齿轮成分占满，轴承成分接近零。

**3. 证据**

| ID | 证据 | 位置 | 获取操作 | 等级 |
|---|---|---|---|---|
| E1-1 | 三副劳保手套，只有一副左手食指磨穿 | 更衣室，老周的旧更衣柜 | 打开柜门、拾取 | G（教学拾取与贴页） |
| E1-2 | 夹在工牌套中的工作照：老周站在车床前，左手伸向主轴箱左端，持听针 | 同一更衣柜门内侧 | 拾取 | **N** |
| E1-3 | 主轴箱左端磨亮的样冲点 + 褪色油漆圈 | LT01 主轴箱左端上方 | 手电照射显出 | **N** |
| E1-4 | 1983 测点示意页：主轴箱剖面简图，L1 指向“后轴承座”，旁注“L1 听后轴承”〔派生，B-1〕 | 交班本贴页（左页） | 翻页 | **N** |
| E1-5 | 衡的 L1 / R1 并排信号条：L1 轴承成分清楚、齿轮成分低；R1 反之 | 衡屏幕（L1 贴听针后衡自动采样） | 贴听针 | **N** |
| E1-6 | 1956 建线合影（贴在柜门） | 更衣柜 | 查看 | A |
| E1-7 | 老周的搪瓷饭盒、工作帽 | 更衣柜 | 查看 | A |

**4. 必要 / 氛围**：必要 E1-2、E1-3、E1-4、E1-5；引导 E1-1；氛围 E1-6、E1-7。

**5. 推理链**
手套只坏左手食指（为什么是左手？）→ 工作照里老周左手持听针伸向主轴箱左端 → 车床前用手电在主轴箱左端找到磨亮的样冲点 → 贴页说明这里是 L1，正对后轴承座 → 让衡在 L1 采样，并排比较：L1 轴承清楚、R1 只有齿轮 → 监测位置应定为 L1。
（要点：左手来自“主轴箱在操作者左手边”的几十年同一动作，**不是左撇子**。）

**6. 三联板正确答案**

| 一联 异常现象 | 二联 经验判断 | 三联 数据特征 |
|---|---|---|
| 右端测点只听得到一片“嗡” | 老周固定在主轴箱左端的 L1 测点听 | L1 对主轴后轴承信噪比更高，监测位置定为 L1 |

**7. Knowledge Rule ID**：`ZHOU_LEFT`（监测位置规则）
**8. 底层工业变量**：`LT01_SPDL_BRG_RR_VIB`（1 号车床主轴后轴承振动，测点 L1）

**9. 错误选项与反馈**

| 格 | 干扰项 | 错误反馈（规则冲突 + 仿真声音） |
|---|---|---|
| 一联 | “左手食指的手套磨穿了” | 衡：`规则冲突：这是证据，不是设备异常。`（教学：区分现象与证据） |
| 一联 | “主轴转速不稳” | 仿真播放稳定转速声，衡：`转速波动 < 0.5%，与现象不符。` |
| 二联 | “老周是左撇子” | 衡：`规则冲突：照片中老周右手扶刀架手柄。`〔派生：照片里右手可见〕 |
| 二联 | “两端各装一个，越多越准” | 仿真：两端信号平均后，咔哒被嗡声淹没 |
| 三联 | “保留 R1，提高增益” | 仿真：增益提高后嗡声同样放大，轴承仍不可读 |
| 三联 | “两端取平均” | 同上 |

**10. 三级提示**（页边批注，周建国笔迹）
- 一级：“他的手套，为什么只坏一只？”
- 二级：“工作照里，他的左手放在哪？”
- 三级：“主轴箱左端，拿手电照一照。”
三联板卡关另有一组：一级“现象是机器的，不是人的。”二级“哪边听得清？”三级“看衡的两条信号条，选清楚的那边。”

**11. 工程事实依据与待核**
- 普通卧式车床主轴箱位于床身左端、操作者左手边（常识，`待核 E-05` 用实物照片确认）。
- 测点越靠近被测轴承座、传递路径越短，信噪比越高（振动监测通用原则，`待核 E-01`，请专业老师审读）。
- **待核 E-05**：真实普通车床主轴箱左端常设挂轮（交换齿轮）罩和皮带轮，L1 若贴近挂轮会同样受齿轮干扰。白盒与 hero 建模须把 L1 放在主轴箱**顶面左端后轴承座正上方**，远离挂轮罩；R1 放在主轴箱前面右侧变速手柄附近、变速齿轮组正上方。这是本机结构设定。

**12. 预计时间**：1:50（取证 1:00，比较 0:20，三联 0:30）

## 3. 谜题二“咔哒在左”（核心听音）

| 项 | 内容 |
|---|---|
| 区域 | 机加工区 LT01（设备特写 CU-1） |
| 剧情内时刻 | 约 17:30 |
| 预计游玩时间 | 3:30（2:30–6:00），首次含提示上限 4:30 |

**1. 衡最初的问题**
通用模型误判：`[17:31] DIAG > 通用模型判定：主轴变速齿轮磨损（置信度 0.71）。建议停机更换齿轮。`

**2. 异常**
车床运转的“嗡”里，夹着一下一下间隔均匀的“咔哒”（在 L1 贴听针时最清楚；整体环境里几乎听不见）。

**3. 证据**

| ID | 证据 | 获取 | 等级 |
|---|---|---|---|
| E2-1 | L1 听音 + 时频图：约 2–4kHz 带状区域内间隔均匀的竖向冲击条纹；播放头与咔哒同步闪亮〔派生，B-3〕；衡在该频带标注“本机共振带（2026 复测）”〔派生，B-2〕 | 听针贴 L1，打开时频图 | **N** |
| E2-2 | R1 听音 + 时频图：衡标出齿轮啮合频率水平亮线 + 边频带指示（处于绿色正常区） | 听针贴 R1 | **N** |
| E2-3 | 1983 设备记录贴页，老周批注“咔哒在左，是轴承；在右，是齿轮”，并写“声尖、脆，像表针”〔派生〕 | 交班本翻页 | **N** |
| E2-4 | 衡的齿轮维修记录：变速齿轮 2022 年更换过〔派生〕 | 衡屏幕 | A（削弱“齿轮磨损”说法的旁证） |
| E2-5 | 周建国对讲机：“嗯。”（完成后） | — | A |

**4. 必要 / 氛围**：必要 E2-1、E2-2、E2-3；氛围 E2-4、E2-5。

**5. 推理链**
衡说齿轮坏了 → 在 R1 听：只有均匀的“嗡”；衡给的啮合线边频带正常 → 齿轮没问题 → 在 L1 听：有“咔哒”，时频图上是周期竖条纹，落在衡标的本机共振带里 → 1983 年老周写“咔哒在左，是轴承” → 这是主轴后轴承的缺陷冲击，衡误判。

**6. 三联板正确答案**

| 一联 | 二联 | 三联 |
|---|---|---|
| “嗡”里夹着“咔哒” | “咔哒在左，是轴承” | L1 测点、本机 2–4kHz 共振带内的周期冲击，作为后轴承缺陷特征；齿轮状态以啮合频率边频带为准 |

玩家操作要求：在 L1 时频图上框出冲击条纹（判定标准见 `03_听音诊断原型_v0.1.md`），并对 R1 边频带指示选择“正常”。

**7. Rule ID**：`ZHOU_CLICK`（诊断规则）
**8. 底层变量**：`LT01_SPDL_BRG_RR_IMP_ALM`（后轴承冲击报警）、`LT01_GB_GMF_SB_IDX`（齿轮啮合边频指标）
**处置结果**〔派生，需确认〕：衡更正诊断为“主轴后轴承早期缺陷，列入计划检修”，撤回“停机换齿轮”建议。车床本班继续运行。

**9. 错误选项与反馈**

| 格 | 干扰项 | 反馈 |
|---|---|---|
| 一联 | “嗡声变大了” | 仿真：按“嗡变大”建模的声音，没有咔哒，玩家听得出不一样 |
| 一联 | “主轴发热” | 衡：`温度 41°C，正常。无对应证据。` |
| 二联 | “在右，是齿轮”（读错了一半批注） | 仿真：按齿轮磨损规则“更换齿轮”后的模拟声——咔哒还在 |
| 二联 | “老机器都这样响” | 仿真：衡按“忽略”处理，咔哒随时间变密〔派生，示意缺陷发展〕 |
| 三联 | “R1 啮合频率幅值升高 = 齿轮磨损” | 衡：`规则冲突：R1 边频带指标在正常区。` |
| 三联 | “全频带能量升高 = 轴承故障” | 衡：`规则冲突：该特征无法区分轴承与齿轮。`（体现“本机特征，不是通用规律”） |

**10. 三级提示**
- 一级：“咔哒在哪边最清楚？”
- 二级：“打开时频图，找一下下竖着的亮条。”
- 三级：“翻到一九八三年那页，老周写过。”

**11. 工程依据与待核**
- 滚动轴承局部缺陷每次被滚动体碾过会产生短促冲击，冲击会激起机械结构的高频共振，在时频图上表现为某一频带内周期性竖条（包络分析的基础）。依据：Brüel & Kjær《Detecting faulty rolling element bearings》（BO0187）。`待核 E-02`（请专业老师确认“激起本机结构共振带”的表述）。
- 齿轮状态以啮合频率及其边频带判断，为振动诊断常规方法，`待核 E-02`。
- 2–4kHz 为本机设定值，不作为通用规律（v1.1 C2）。
- 年代口径：1983 年老周的“标定”是位置与听感，不含频带数值（B-2）。

**12. 预计时间**：3:30（听 L1/R1 1:20，框选与判断 0:50，翻贴页 0:30，三联 0:50）

**5. 推理链**

**11. 工程依据与待核**
- ZV（zero vibration）输入整形：把指令拆成两段，第二段在约半个阻尼振荡周期处给出，两段引起的振荡反相抵消。依据：Singer & Seering 1990（输入整形经典论文）；Wikipedia “Input shaping” 中 1Hz 示例为两段各半幅、第二段在 0.5s（半个周期）给出。`待核 E-04`：请专业老师确认“稳钩手法 ↔ ZV 整形”的类比表述。
- 单摆周期 T = 2π√(L/g)，L=4.0m 时约 4.0s（计算值）。阻尼对周期影响很小，原型中忽略。
- “吊钩挂盛水搪瓷缸考徒弟”是本作虚构的班组做法，`存疑 K-14`，不作为史实宣称。
